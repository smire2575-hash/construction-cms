# CMS — Xaaladda 24-ka Modules (Development v0.1)

**Lama beddelin scope-ka Full 24-Module System.** Mashruuca hal mar laguma sheegayo inuu dhammaaday ilaa dhammaan specialized workflows, database, security iyo tests la dhammaystiro.

| Module | Hadda jira | Waxa dhiman |
|---|---|---|
| Discuss | Navigation + generic records | Channels, real-time chat, moderation |
| Calendar | Navigation + generic records | Calendar event scheduling, invites |
| Appointments | Navigation + generic records | Slot booking, reminders |
| To-do | Create/list demo, Supabase API tasks | Assignments, deadlines, reporting |
| Knowledge | Navigation + generic records | Articles, revisions, publishing |
| Contacts | Create/list demo/live | Customer ledger, supplier ageing |
| CRM | Navigation + contacts view | Leads, pipeline, conversion |
| Sales | Demo sale + live atomic POS sale | Quotation, order, partial delivery, full invoices |
| Dashboards | KPIs and demo charts | True backend KPI aggregation, filters |
| Point of Sale | Demo checkout | Cashier shifts, return/receipt/credit workflows |
| Accounting | Demo P&L view + atomic sale journal | General Ledger UI, AR/AP, full reports, FX |
| Documents | Upload endpoint to Supabase Storage | Document listing, versions and previews |
| Project | Navigation + generic records | Budgets, milestones, costing |
| Planning | Navigation + generic records | Resources, scheduling, conflicts |
| Surveys | Navigation + generic records | Forms, response analysis |
| Purchase | Pending purchase records | Supplier bills, receiving, costing |
| Inventory | Products/stock, sale deductions | AVCO receiving, transfers, count, full warehouses |
| Barcode | Product browsing | Scanner, label generation/print |
| Sign | Navigation + generic records | Secure signature requests, verification |
| Employees | Demo employees, live memberships list | Invites, granular permissions, HR detail |
| Expenses | CRUD simple/pending records | Approvals, journals, reimbursements |
| WhatsApp | Navigation + generic records | Meta API provider integration |
| Apps | Catalog list | Pricing and custom tenant entitlement UI |
| Settings | Company limits preview | Full branch settings and templates |

## Habka dhismaha ee xiga

Foundation → Super Admin billing → Company branches/users → Sales/Inventory/Purchase/AVCO → GL/FX/Reports → Remaining Modules → End-to-end Testing → Hosted deployment.

**Nabadgelyada live beta:** Business APIs ee tenant-ka waxaa hadda loo oggolyahay Primary Owner keliya ilaa branch/employee permission scope-ka si buuxda loo hirgeliyo loona tijaabiyo. Demo-only employee pages waa tusaale.
